# kabu — 押し目買いバックテスト

単一銘柄の「押し目買い」短期戦略をバックテストするツール。

## 公開 URL

- **Web（Vercel）**: https://web-five-gamma-71.vercel.app
- **GitHub**: https://github.com/atsushi2330/kabu

## ローカル起動

### Streamlit（フル機能・パラメータ探索あり）

```bash
pip install -r requirements.txt
streamlit run app.py
```

### Next.js（Vercel と同じ UI）

```bash
cd web
npm install
npm run dev
```

詳細は [DEPLOY.md](DEPLOY.md) を参照。
